# Техническое задание: Обработка данных о просрочках платежей

## Цель

Разработать функцию `generate_report(sheet1, sheet2, sheet3)`, которая принимает данные с трёх листов Google Sheets, рассчитывает задолженности студентов по рассрочке на 1 марта 2023 года и сохраняет отчёт в файл `student_debt_report.txt`.

## Исходные данные

Три листа Google Sheets, загружаемые через `gspread`:

- **Лист 1:** `student_id`, `student_name`, `installment` (Y/N)
- **Лист 2:** `student_id`, `last_payment_date` (DD.MM.YYYY), `expected_payment_date` (DD.MM.YYYY)
- **Лист 3:** `student_id`, `already_payed_amount`, `left_to_pay`, `one-time_payment`, `installment_amount`

## Логика расчёта

Учитываются только студенты с `installment = 'Y'`. Расчётная дата — 1 марта 2023 года. Период платежа — 183 дня. Если `expected_payment_date` меньше 1 марта 2023, считается просрочка. Количество просроченных периодов — разница в днях между 1 марта и `expected_payment_date`, делённая на 183, с округлением вверх. Долг равен `one_time_payment * количество_периодов`, но не может превышать `left_to_pay`.

## Выходные данные

Файл `student_debt_report.txt` в кодировке UTF-8. Каждая строка: `Студент Фамилия И.О. - долг X рублей`. Студенты с долгом 0 не включаются.

## Критерии приёмки

- Функция принимает три списка словарей
- Обрабатываются только студенты с активной рассрочкой
- Корректно рассчитывается количество просроченных периодов
- Долг не превышает оставшуюся сумму выплаты
- Выходной файл полностью совпадает с эталонным
- Для авторизации используется `creds.json`

## Примечания

Даты в Sheet2 в формате `DD.MM.YYYY`. Суммы в Sheet3 могут требовать приведения к числовому типу. Период платежа фиксированный — 183 дня. Расчётная дата жёстко задана как 1 марта 2023 года.
