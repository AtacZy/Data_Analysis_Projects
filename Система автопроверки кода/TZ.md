# Техническое задание: Система автопроверки кода

## Цель

Разработать систему автоматической проверки пользовательского кода, которая запускает тесты, выявляет вредоносный код и контролирует время выполнения.

## Исходные данные

- `etalon.py` — эталонный код с правильной реализацией функции `add(a, b)`
- `user.py` — пользовательский код с функцией `add_numbers(a, b)`
- `res_cor.txt` — эталонный файл с ожидаемым выводом

Тестовые случаи: `[(1, 2), (3, 4), (5, 6)]`.

## Задача 1: run_tests

Функция принимает эталонную функцию, пользовательскую функцию, список тестовых случаев и путь к выходному файлу. Для каждого теста функции вызываются с одинаковыми аргументами, результаты сравниваются. Выходной файл заполняется построчно: "Тест пройден" при совпадении, "Тест не пройден" с деталями при расхождении. При ошибке в эталонном или пользовательском коде проверка останавливается, сообщение записывается в файл.

## Задача 2: check_for_malicious_code

Функция принимает исходный код и путь к выходному файлу. Код разбирается через `ast.parse`. Запрещены: вызов `eval()`, атрибуты `eval` и `exec`. При обнаружении запрещённых конструкций записывается сообщение об ошибке. При синтаксической ошибке также пишется сообщение. При чистом коде записывается подтверждение.

## Задача 3: Контроль времени

Модификация `run_tests`: пользовательский код запускается в отдельном процессе через `multiprocessing.Process` с таймаутом 5 секунд. При превышении времени процесс завершается, записывается предупреждение. Результат из процесса передаётся через `Queue`.

## Критерии приёмки

- `output.txt` полностью совпадает с `res_cor.txt`
- `output2.txt` полностью совпадает с `cor_output_2.txt`
- `output3.txt` полностью совпадает с `cor_res_3.txt`
- Вредоносный код детектируется, проверка не запускается
- Бесконечный цикл прерывается по таймауту, проверка останавливается

## Примечания

Модули импортируются через `importlib.import_module`. Исходный код модуля извлекается через `inspect.getsource`. Для таймаута используется `multiprocessing.Process` с `join(timeout=5)`. Результат выполнения пользовательской функции передаётся через `multiprocessing.Queue`.
