# Проект: Обработка данных о просрочках платежей

**Тип задачи:** финансовая аналитика, работа с внешними данными  
**Источник:** Google Sheets  

## Описание проекта

Образовательная платформа ведёт учёт студентов, оформивших рассрочку на обучение. Данные хранятся в Google Sheets на трёх листах. Задача — собрать данные через API, обработать их и сформировать отчёт о должниках по состоянию на 1 марта 2023 года.

## Данные

**Лист 1 — информация о студентах:** идентификатор студента, имя, наличие рассрочки.

**Лист 2 — платежи:** идентификатор студента, дата последней оплаты, ожидаемая дата следующего платежа.

**Лист 3 — суммы:** идентификатор студента, уже выплаченная сумма, оставшаяся сумма, размер единоразового платежа, общая сумма рассрочки.

Период внесения платежей для всех студентов одинаков — 183 дня, то есть 6 месяцев.

## Логика работы

Данные импортируются из Google Sheets через библиотеку `gspread` с авторизацией по сервисному аккаунту. Три списка объединяются в общий словарь, где ключ — идентификатор студента. Для каждого студента с активной рассрочкой проверяется, наступила ли дата ожидаемого платежа раньше 1 марта 2023 года. Если да — считается количество просроченных периодов и сумма долга. Итоговый отчёт сохраняется в текстовый файл.

## Особенности расчёта

Учитываются множественные просрочки. Если студент пропустил несколько платежей подряд, каждый период увеличивает долг на сумму одного платежа. Итоговый долг не может превышать оставшуюся к выплате сумму. Студенты без долга в отчёт не попадают.

## Используемые библиотеки

- `gspread` — доступ к Google Sheets API
- `oauth2client` — авторизация через сервисный аккаунт
- `datetime`, `timedelta` — работа с датами и периодами
- `math` — округление количества периодов просрочки
- `pandas` — проверка результата

## Результат

Текстовый файл `student_debt_report.txt`, где каждая строка содержит информацию о студенте-должнике в формате: "Студент Фамилия И.О. - долг X рублей".
