# Проект: Обработка чеков о продажах (CSV)

**Тип задачи:** автоматизация обработки данных  
**Источник:** CSV-файлы с чеками, имя в формате `YYYY-MM-DD-HH-MM-N.csv`  

## Описание проекта

Компания хранит чеки о продажах в виде CSV-файлов в папке `reports-main`. Каждый файл содержит дату, название продукта и цену, разделитель — точка с запятой. Имя файла представляет собой временную метку. Задача — написать функцию `process_files`, которая собирает все подходящие чеки, объединяет их и сохраняет в отсортированный отчёт.

## Логика работы

Сначала через `glob.glob` собираются все CSV-файлы из исходной папки. Затем регулярным выражением отфильтровываются только те, чьё имя соответствует шаблону `ГГГГ-ММ-ДД-ЧЧ-ММ-N.csv`. Каждый отобранный файл читается построчно: первая строка забирается как заголовок, остальные складываются в список словарей. После объединения данные сортируются по дате, а затем по названию продукта. Результат записывается в файл `combined_data.csv` в папку назначения. Если папки назначения нет, она создаётся автоматически.

## Используемые библиотеки

- `pandas` — проверка результата
- `glob` — поиск файлов по шаблону
- `os` — работа с путями и папками
- `re` — фильтрация имён файлов
- `csv` — чтение и запись данных

## Результат

На выходе файл `combined_data.csv` с колонками `date`, `product`, `price`. Данные отсортированы по дате по возрастанию, внутри одной даты — по алфавиту продукта.

## Проверка

Результат сравнивается с эталонным ответом через `assert`: пользовательский `combined_data.csv` должен полностью совпадать с `data.csv`, включая порядок колонок и значения.
