# Проект: Различные бизнес-кейсы на Python

**Тип задачи:** решение практических бизнес-задач с использованием ООП и стандартной библиотеки Python  

## Описание проекта

Сборник из пяти независимых бизнес-кейсов, решённых с использованием стандартной библиотеки Python и объектно-ориентированного подхода. Каждый кейс моделирует реальную задачу аналитика или разработчика. Акцент сделан на работу с датами, группировками, агрегациями и построением чистых пайплайнов обработки данных.

## Кейс 1: Анализ рекламы через стандартный Python

Анализ данных рекламных кампаний без использования pandas. Чтение CSV через модуль `csv`, агрегация метрик, расчёт конверсий и эффективности объявлений. Демонстрируется, что базовые аналитические задачи решаются встроенными средствами языка.

## Кейс 2: Выгрузка активности IT Resume

Обработка и анализ данных по активности резюме IT-специалистов. Выгрузка содержит информацию о должностях, навыках, опыте и активности соискателей. Данные структурируются, выделяются ключевые метрики активности, результат представляется в удобном для отчётности виде.

## Кейс 3: ETL продажи

Построение ETL-пайплайна для обработки данных о продажах. Включает извлечение данных из файлов, трансформацию (очистка, приведение типов, агрегация) и загрузку результата. Пайплайн построен с использованием классов, инкапсулирующих логику каждого этапа.

## Кейс 4: Пользовательские сессии

Анализ логов пользовательских сессий. Восстановление цепочек действий пользователей, выделение сессий по времени бездействия, расчёт ключевых метрик: длительность сессий, количество действий, точки выхода. Активно используются `datetime`, `timedelta` и `groupby` из `itertools`.

## Кейс 5: Трек задач

Система учёта и отслеживания задач с применением ООП. Задачи описываются классами с атрибутами: название, приоритет, статус, дедлайн. Реализованы методы для создания, обновления, фильтрации и сортировки задач. Демонстрируется работа с `functools` и сортировками по нескольким ключам.

## Используемые библиотеки

- `csv` — чтение и запись CSV-файлов
- `json` — работа с JSON-данными
- `datetime`, `date`, `timedelta` — обработка дат, времени и временных интервалов
- `collections`, `defaultdict`, `Counter` — специализированные контейнеры
- `itertools.groupby` — группировка данных по ключу
- `operator.itemgetter` — удобное извлечение элементов для сортировок и группировок
- `functools` — декораторы и функции высшего порядка
- `statistics` — вычисление средних, медиан и других статистических показателей
- `os`, `glob` — работа с файловой системой

## Особенности реализации

- Активное применение объектно-ориентированного подхода для структурирования кода
- Группировка и агрегация данных через `groupby` и `defaultdict`
- Работа с датами: парсинг, форматирование, расчёт разниц через `timedelta`
- Сортировки по составным ключам через `itemgetter`
- Статистические расчёты через модуль `statistics`

## Запуск

Каждый кейс — отдельный Jupyter-ноутбук, запускается независимо. Зависимостей кроме стандартной библиотеки Python не требуется.

```bash

jupyter notebook Кейс_ETL_продажи.ipynb
jupyter notebook Пользовательские_сессии.ipynb
jupyter notebook Трек_задач.ipynb
