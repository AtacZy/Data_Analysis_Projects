# Статистический анализ продаж на Wildberries

Оптимизация продуктовой линейки и оценка эффективности рекламы селлера.

## Описание проекта

Статистический анализ данных селлера Wildberries за июнь-июль 2023 года. Цель — найти точки роста прибыли через оптимизацию ассортимента, отказ от неэффективных акций, перераспределение рекламного бюджета и улучшение контента карточек товаров.

## Бизнес-контекст

Бренд kaoki продаёт три товара: шорты ментол, штаны ментол и штаны графит. Общая выручка за 2 месяца — 4.67 млн руб, прибыль — 853 тыс руб. При высокой доле отказов (25-39%) и неочевидной эффективности акций требуется понять, какие товары масштабировать, а какие снять с продажи.

## Данные

Нормализованный файл `wb_data_normalized.xlsx` (модель "Звезда", 5 таблиц):
- `dim_Товары` — артикулы, бренды
- `dim_Календарь` — даты, дни недели, недели, месяцы
- `fact_Продажи` — заказы, выкуп, отказы, возвраты, цены
- `fact_Финансы` — прибыль, себестоимость, логистика, штрафы
- `fact_Маркетинг` — источники трафика, бюджеты рекламы

## Структура анализа

1. Загрузка и очистка данных
2. Описательная статистика по артикулам
3. Проверка нормальности распределений
4. Визуализация ключевых метрик
5. Проверка 10 статистических гипотез
6. Расчёт точки безубыточности при изменении цены
7. Итоговые выводы и рекомендации

## Методология

Все ключевые метрики показали ненормальное распределение (тест Шапиро-Уилка, p = 0.0000). Поэтому использованы непараметрические критерии:

| Задача | Критерий |
|--------|----------|
| Сравнение двух групп | U-критерий Манна-Уитни |
| Сравнение трёх и более групп | Критерий Краскела-Уоллиса |
| Корреляция | Коэффициент Спирмена |
| Равномерность распределения | Хи-квадрат |

Для попарных сравнений применялась поправка Бонферрони.

## Проверенные гипотезы

### Блок 1: Акции и ценообразование
- **H1:** Влияние акций на выручку → различий нет (p = 0.0877)
- **H2:** Влияние акций на средний чек → различий нет (p = 0.1448)

### Блок 2: Продуктовая линейка
- **H3:** Прибыль на единицу по товарам → различается (p = 0.0003). Шорты ментол vs Штаны графит: +343 руб/шт
- **H9:** Процент выкупа по товарам → различается (p = 0.0000). Разница 22% между лучшим и худшим

### Блок 3: Отказы и возвраты
- **H4:** Связь отказов и выкупа → нет связи (p = 0.7935)
- **H10:** Связь цены и возвратов → нет связи (p = 0.8859)

### Блок 4: Реклама
- **H5:** Связь бюджета рекламы и заказов → положительная связь (rho = 0.59, p = 0.0000). Медианный ROAS = 32.9x

### Блок 5: Сезонность
- **H6:** Равномерность заказов по дням → неравномерно (p = 0.0000). Пик: Пн (30 заказов), спад: Сб (16 заказов)
- **H7:** Выручка по дням недели → различий нет (p = 0.9595)

### Блок 6: Ценообразование
- **H8:** Связь цены и выкупа → сильная отрицательная (rho = -0.69, p = 0.0000). В низком сегменте 72.8%, в высоком 58.9%

## Ключевые выводы

1. Акции неэффективны — не повышают ни выручку, ни заказы. Рекомендован отказ от участия.
2. Штаны графит — кандидат на снятие с продажи (выкуп 50%, маржа 8.9%, прибыль на единицу значимо ниже).
3. Шорты ментол — лидер, рекомендовано масштабирование.
4. Реклама окупается (ROAS = 32.9x), бюджет перераспределить на Пн-Вт.
5. Высокая доля отказов (25-39%) требует улучшения карточек: фото, видео, размерная сетка.
6. Снижение цены на 5-10% для шорт может повысить выкуп без потери выручки (расчёт точки безубыточности).

## Ожидаемый эффект

При внедрении всех рекомендаций — рост прибыли на 25-30% без дополнительных затрат.
