# Проект: Система автопроверки кода

**Тип задачи:** разработка инструмента для автоматической проверки пользовательского кода  
**Источник:** Python-файлы с эталонным и пользовательским кодом  

## Описание проекта

Разработка системы автоматической проверки кода, которая сравнивает пользовательское решение с эталонным. Система последовательно выполняет три задачи: прогон тестов, проверку на вредоносный код и контроль времени выполнения.

## Задача 1: Запуск тестов

Функция `run_tests` принимает эталонную функцию, пользовательскую функцию, список тестовых случаев и имя выходного файла. Для каждого теста обе функции вызываются с одинаковыми аргументами, результаты сравниваются. При совпадении в файл записывается "Тест пройден", при расхождении — "Тест не пройден" с ожидаемым и фактическим результатами. При возникновении ошибки информация об ошибке записывается в выходной файл, проверка останавливается.

## Задача 2: Проверка на вредоносный код

Функция `check_for_malicious_code` анализирует пользовательский код через модуль `ast`. Код преобразуется в абстрактное синтаксическое дерево, по которому производится поиск запрещённых конструкций: вызовов `eval()` и атрибутов `exec`. При обнаружении вредоносного кода в выходной файл записывается сообщение об ошибке, и проверка не запускается. Если код чистый, записывается подтверждение безопасности.

## Задача 3: Контроль времени выполнения

В функцию `run_tests` добавляется ограничение по времени. Пользовательский код запускается в отдельном процессе через `multiprocessing`. Если время выполнения превышает 5 секунд, процесс принудительно завершается, а в выходной файл записывается предупреждение. Это защищает систему от бесконечных циклов и неоптимальных решений.

## Используемые библиотеки

- `importlib` — динамический импорт модулей
- `inspect` — получение исходного кода модуля
- `ast` — разбор кода в синтаксическое дерево для проверки безопасности
- `multiprocessing` — запуск кода в отдельном процессе с таймаутом
- `time` — замер времени выполнения
