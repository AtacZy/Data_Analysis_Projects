# Техническое задание: Обработка логов о подписках

## Цель

Разработать три функции для автоматического анализа логов подписочного сервиса: подсчёт статистики продлений, анализ динамики автопродлений и распределение продлений по дням недели.

## Исходные данные

Лог-файл `auto_purchase.log` с разделителем `|`. Формат одной строки: `система | дата и время | служебное поле | служебное поле | сообщение`. Временная метка в формате `YYYY-MM-DD HH:MM:SS,микросекунды`. Сообщение может содержать префикс `[demon]`.

## Задача 1: count_success_and_failure

Функция принимает путь к файлу, возвращает кортеж `(success, failure)`. Успешные попытки — строки с `Обновляем подписку пользователю id:`, неуспешные — строки с `ошибка при списании`. Итоговое количество успешных рассчитывается как разница между найденными обновлениями и ошибками. Эталонный результат: `(1034, 186)`.

## Задача 2: auto_renewal_sub

Функция принимает путь к файлу, сохраняет результат в `auto_renewal_sub.txt`. Логи преобразуются в список словарей с полями `timestamp`, `message`, `system`. Отбираются строки с `количество людей с автопродлением подписки`. Данные группируются по дате, для каждой даты сохраняется максимальное значение. По полученному списку значений считается скользящее среднее и скользящая медиана по всем предыдущим элементам, включая текущий. Результат записывается с заголовками `Среднее:` и `Медиана:`.

## Задача 3: sub_renewal_by_day

Функция принимает путь к файлу, сохраняет результат в `weekdays.txt`. Из логов отбираются успешные продления по строке `Обновляем подписку пользователю id:`. Дата каждого продления преобразуется в день недели на русском языке. Подсчитывается количество продлений для каждого дня через `Counter`. Результат записывается с заголовком `Количество обновлений подписки по дням недели:` и построчным списком дней.

## Критерии приёмки

- `count_success_and_failure` возвращает `(1034, 186)`
- `auto_renewal_sub.txt` полностью совпадает с эталонным файлом `cor_auto_renewal.txt`
- `weekdays.txt` полностью совпадает с эталонным файлом `cor_weekdays.txt`
- Все функции принимают путь к файлу как единственный аргумент
- Файлы результатов сохраняются в кодировке UTF-8

## Примечания

Поле `message` требует очистки от префикса `[demon]`. Дни недели выводятся на русском языке: Понедельник, Вторник, Среда, Четверг, Пятница, Суббота, Воскресенье. При фильтрации успешных продлений учитывается связка с последующей строкой для исключения дублирования.
