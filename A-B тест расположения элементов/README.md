# A/B-тест изменения расположения элементов на платформе Marketpele

## О проекте

Проект посвящён полному циклу A/B-тестирования: от дизайна эксперимента до анализа результатов и подготовки рекомендаций для бизнеса.

**Платформа:** Marketpele

**Суть теста:**  
Marketpele показывает пользователям два типа элементов:

- **Органические** — ссылки на статьи издателя
- **Платные** — рекламные объявления, при клике на которые платформа получает доход

Было предположение, что изменение расположения платных и органических элементов может повлиять на конверсию в клики и, как следствие, на выручку.

---

## Цели проекта

- Провести предобработку и разведочный анализ исторических данных
- Спроектировать A/B-тест: выбрать метрики, рассчитать MDE, длительность и размер выборки
- Проверить корректность дизайна через AA-тест и симуляцию
- Применить CUPED для повышения чувствительности
- Проанализировать результаты эксперимента
- Сделать выводы и дать рекомендации бизнесу

## Методология

### Предобработка данных

- Проверка типов данных
- Проверка пропусков и дубликатов
- Удаление выбросов методом IQR (порог 3×IQR)

### EDA

- Анализ распределений (violin plot)
- Сравнение метрик по устройствам
- Анализ активности по дням недели
- Расчёт CTR метрик
- Корреляционный анализ

### Дизайн теста

- Уровень значимости: α = 0.05
- Мощность: 0.80
- Длительность: 3 недели
- Доля трафика: 50/50
- MDE для ctr_paid: 5.09%
- MDE для revenue: 1.07% (с CUPED)

### Проверка дизайна

- AA-тест: FPR = 0.045
- Симуляция A/B-теста: мощность = 1.000

### CUPED

- Ковариата: pages_viewed
- Снижение дисперсии revenue: 28.65%

## Основные результаты

| Метрика | Control | Test | Разница | p-value | Значимость |
|---|---|---|---|---|---|
| ctr_paid | 0.2365 | 0.2741 | +15.9% | 0.0000 | Да |
| ctr_organic | 0.3460 | 0.2604 | -24.7% | 0.0000 | Да |
| revenue | 173.55 | 174.27 | +0.4% | 0.9198 | Нет |

---

## Выводы

- CTR платных кликов статистически значимо вырос на **+15.9%**
- CTR органических кликов статистически значимо упал на **-24.7%**
- Доход значимо не изменился

**Итог:** изменение расположения перераспределило клики, но не увеличило доход.
