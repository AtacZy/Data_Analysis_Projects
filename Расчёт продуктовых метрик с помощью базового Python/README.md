# Проект: Расчёт продуктовых метрик онлайн-платформы

**Тип задачи:** продуктовая аналитика  
**Источник:** данные о регистрациях и входах пользователей  

## Описание проекта

Онлайн-платформа предоставляет данные о регистрациях пользователей и их входах на платформу. Задача — рассчитать ключевые продуктовые метрики, которые используются для оценки здоровья продукта и принятия бизнес-решений.

## Метрики

**Retention 15 дня** — доля пользователей, зарегистрированных в январе, которые вернулись на платформу ровно на 15-й день после регистрации. Результат — 54.65%.

**Rolling retention 30 дня** — доля пользователей из январской когорты, которые заходили на платформу на 30-й день или позже. Результат — 29.07%.

**Lifetime** — среднее количество дней, которое пользователь остаётся активным. Рассчитывается как сумма отношений количества входов в каждый день к количеству входов в нулевой день по всем пользователям. Результат — 14.804 дня.

**Churn rate 29 дня** — доля пользователей, не имевших входов на 29-й день или позже, от общего числа зарегистрированных. Результат — 0.509.

**MAU, WAU, DAU** — метрики активной аудитории за месяц, неделю и день. Рассчитываются двумя способами: за последний период и как среднее значение по всем периодам.

## Результаты
