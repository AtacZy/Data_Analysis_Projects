# Портфолио проектов по аналитике данных

Привет! Меня зовут **[Андрей]**. Я аналитик данных, специализируюсь на автоматизации обработки данных, построении ETL-пайплайнов и анализе бизнес-показателей.

В этом репозитории собраны мои проекты, демонстрирующие навыки работы с Python, SQL, API, инструментами автоматизации и визуализации, а также применение методов анализа, статистики и A/B-тестирования.
