
# Техническое задание: Обработка чеков о продажах в формате 'csv'

## Цель:

Разработать функцию `process_files(src_folder, dest_folder)`, которая принимает путь к папке с чеками и путь к папке для сохранения результата. Функция должна отобрать все CSV-файлы с именем по шаблону, объединить их содержимое, отсортировать по дате и продукту, сохранить как `combined_data.csv`.

## Исходные данные

Файлы формата CSV с разделителем `;`. Имя файла соответствует шаблону `YYYY-MM-DD-HH-MM-N.csv`, где N — любое число. Внутри каждого чека три колонки: `date`, `product`, `price`. Файлы находятся в папке, переданной первым аргументом функции.

## Выходные данные

Один CSV-файл `combined_data.csv` с разделителем `,` и кодировкой UTF-8. Колонки: `date`, `product`, `price`. Сортировка: сначала по дате от старых к новым, затем по названию продукта в алфавитном порядке. Файл сохраняется в папку, переданную вторым аргументом.

## Этапы работы

1. Получить список всех файлов с расширением `.csv` из исходной папки
2. Отфильтровать по регулярному выражению `\d{4}-\d{2}-\d{2}-\d{2}-\d{2}-\d+.csv`
3. Прочитать каждый отобранный файл: первую строку взять как заголовок, остальные строки разобрать в список словарей
4. Объединить все записи в один список
5. Отсортировать по ключам `date` и `product`
6. Записать результат в `dest_folder/combined_data.csv`

## Критерии приёмки

- Функция принимает два строковых аргумента: путь-источник и путь-назначение
- Отбираются только CSV-файлы, соответствующие шаблону имени
- Все чеки корректно объединены в один набор данных
- Данные отсортированы строго по дате, затем по продукту
- Результат сохранён как `combined_data.csv` в нужной папке
- Файл полностью совпадает с эталонным ответом при проверке через `assert`
- Папка назначения создаётся автоматически при отсутствии

## Примечания

Разделитель в исходных файлах — точка с запятой, в выходном — запятая. Имя файла для проверки регуляркой извлекается через `os.path.basename()`. При отсутствии подходящих файлов функция должна обрабатывать ситуацию без падения.
